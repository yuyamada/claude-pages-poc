# claude-pages-poc

PoC: publish content generated by [Claude Code Action](https://github.com/anthropics/claude-code-action) to GitHub Pages.

## How it works

1. Trigger the `Generate and Deploy to Pages` workflow manually (Actions tab → Run workflow, or `gh workflow run`).
2. A shell step computes the current UTC timestamp.
3. The `generate` job runs Claude Code Action in automation mode, which writes a new dated report to `site/reports/<timestamp>.html` and rewrites `site/index.html` to list every report under `site/reports/`, newest first.
4. A plain shell step commits and pushes those changes to `main`, so report history persists across runs.
5. `actions/upload-pages-artifact` uploads the full `site/` directory (all past reports plus the index), and the `deploy` job publishes it via `actions/deploy-pages`.

## One-time setup

- Repository secret `CLAUDE_CODE_OAUTH_TOKEN` must be set (Settings → Secrets and variables → Actions). Generate it locally with `claude setup-token` (requires a Pro/Max/Team/Enterprise subscription).
- Pages source must be set to "GitHub Actions" (Settings → Pages → Build and deployment).

## Note

The workflow trigger is `workflow_dispatch`. Official Claude Code Action documentation is inconsistent about whether this event is fully supported yet ([one doc says "coming soon"](https://github.com/anthropics/claude-code-action/blob/main/docs/custom-automations.md)); this repo is partly to verify that in practice. If it doesn't work, the fallback is a `repository_dispatch` trigger fired via the GitHub API.
